TRY IT YOURSELF

A 10-MINUTE WALKTHROUGH

The best way to decide if this app is right for the brewery is to play with it. This guide walks you through every screen as if it were a real DJ night, complete with a few "what if?" scenarios to test the edges. Grab your phone and a laptop (or two phones), set aside ten minutes, and let's go.

OPEN THIS IN ANY BROWSER inner-groove-dj.vercel.app
⚙️ BEFORE YOU START

For the full experience, you'll want to see all three views at once:

  • Phone — for the patron view (acts like a real customer)
  • Laptop or tablet — for the admin/DJ console
  • A second screen if you can — for the big-screen display (a TV is ideal, but any browser tab works)

If you only have one device, that's fine — just switch between the three views using the buttons at the bottom of the screen. The experience is just more dramatic with multiple screens because you'll see real-time updates fly across all of them at once.

⚠️ Note: The app is live in test mode, so anything you add to the queue is visible to anyone else who's also testing. Just clear the queue from the Admin → Queue tab when you're done.

PART 1: THE PATRON EXPERIENCE

This is what your customers will see when they scan a QR code at their table.

01
OPEN THE APP

Go to inner-groove-dj.vercel.app on your phone.

At the bottom of the screen, you'll see three buttons. Tap 📱 Patron if it isn't already selected.

WHAT YOU SHOULD SEE A glowing "INNER GROOVE BREWING" header, a request form for song / artist / your name / tip amount, and the current queue below.
02
SUBMIT A REQUEST WITH NO TIP

Type in any song you'd actually want to hear (e.g. Sweet Caroline — Neil Diamond), put your name, leave the tip at "No tip," and tap the big green PREVIEW REQUEST button.

Confirm on the next screen, and you'll land on a "REQUEST SUBMITTED!" page.

WHAT YOU SHOULD SEE Your song appears at the bottom of the queue. If you have the Display view open on a TV or another tab, it shows up there in real time too — no refresh needed.
03
SUBMIT A SECOND REQUEST WITH A TIP

Tap "Submit another request." This time pick a different song (e.g. Don't Stop Believin' — Journey), put a different name in (pretend to be a different patron), pick a $5 tip, and toggle ⚡ Jump the Line.

Choose between paying with the configured payment method or checking 💵 I'll tip cash at the bar — try both flows on different requests to see how each behaves.

WHAT YOU SHOULD SEE Your new song jumps to the top of the queue with an ↑ $5 indicator. If you chose Venmo, the Venmo app opens (you can cancel — no real payment needed). If you chose cash, the bump applies immediately with no payment redirect.
04
TIP ON SOMEONE ELSE'S SONG

Scroll down to the queue at the bottom of the patron form. Tap any song already in the queue.

A modal pops up with two big buttons: ⬆ BUMP UP and ⬇ BUMP DOWN.

Try BUMP UP first — pick $2, leave the name blank (it'll show as "Anonymous"), and submit.

Then tap a different song and try BUMP DOWN — note the higher minimum ($3 by default).

WHAT YOU SHOULD SEE The bumped song moves up with an updated tip total. The down-bumped song moves lower (or to the bottom). On the Display view, the queue rearranges in real time and the tip totals are visible on each song.
05
TRY TO REQUEST A DUPLICATE

Submit a song that's already in the queue — same title, doesn't matter who originally requested it.

WHAT YOU SHOULD SEE A friendly message saying "[Song] is already in the queue. Tap it below to bump it instead!" — preventing duplicate requests and pushing tip-driven engagement.

PART 2: THE BIG SCREEN

This is what plays on the TV in the brewery. The brand-defining piece of the experience.

06
SWITCH TO THE DISPLAY VIEW

Tap 📺 Display at the bottom. If you can, open this in a separate browser window or on a TV — full-screen it (F11 on most browsers, or use Chromecast / AirPlay) to see what patrons will actually look at.

WHAT YOU SHOULD SEE A massive glowing ▶ UP NEXT card with the top song. Below it, a list of the next 6 songs. In the top right, the time (or charity total if charity mode is on). If patrons have tipped, a 🏆 TOP TIPPERS leaderboard sits in the header. A ticker at the bottom rotates between announcements and recently played songs.
07
WATCH IT LIVE

While the Display view is open, go back to the patron view on another device (or another tab) and submit a new request, or bump an existing song.

WHAT YOU SHOULD SEE The Display view updates instantly — songs slide into place, tip totals refresh, the leaderboard re-ranks. No page refresh needed. This is the magic patrons will see across the bar.

PART 3: THE DJ CONSOLE

This is what your DJ or bar staff uses to manage the night.

08
LOG IN AS ADMIN

Tap 🎛️ Admin at the bottom. You'll be prompted for a PIN.

Enter 1234 (this is the placeholder PIN — Brian will swap it for a real one before launch).

WHAT YOU SHOULD SEE The DJ Console opens with five tabs across the top: QUEUE, PAYMENT METHODS, CHARITY MODE, DISPLAY, and RULES.
09
MARK A SONG AS PLAYED

On the QUEUE tab, find a song and tap the green ✓ PLAYED button.

WHAT YOU SHOULD SEE The song disappears from the queue. The Display view updates instantly. If you submit another song after this, the played song will appear in the "JUST PLAYED:" portion of the bottom ticker on the Display view.
10
EXPLORE THE OTHER TABS

PAYMENT METHODS — Add or remove ways patrons can tip. Every method you add (Venmo, Cash App, PayPal, Zelle, custom URL) shows up as an option on the patron side.

CHARITY MODE — Try toggling this on. Set a charity name like "Pittsburgh Food Bank" and a custom header like "Tunes for a Cause." Then check the Display view — the entire experience transforms.

DISPLAY — Toggle whether tip totals are shown publicly. Useful if you want a more low-key vibe or to hide the bidding war.

RULES — Set a per-person request cap. Try setting it to 2, then go back to the patron view and try submitting 3 songs under the same name.

SCENARIOS WORTH TESTING

The features above are the basics. To really stress-test the app, try these specific situations:

SCENARIO A
A BUMP-DOWN WAR
Submit a song under one name (say "Mike"). Then under a different name, tap that song and BUMP IT DOWN with $5. Then under a third name, BUMP IT BACK UP with $10. Watch the Display view rearrange the queue based on net tips. Now you understand why patrons will keep pulling out their phones.
SCENARIO B
CHARITY NIGHT
Turn on Charity Mode in admin. Set a charity name and custom header. Submit a few requests with tips on the patron side. Watch the running $ RAISED counter climb in real time on the Display view. When you're done, hit "RESET CHARITY TOTAL" to start fresh.
SCENARIO C
THE QUEUE-HOG
Set the request cap to 2 in the Rules tab. Pretend to be one patron and submit 3 songs with the same name. The third one will be blocked with a friendly message telling them to wait or bump existing songs. This protects the queue from being dominated by one person.
SCENARIO D
THE LEADERBOARD COMPETITION
Submit several requests as different patrons with varying tip amounts. Watch the 🏆 TOP TIPPERS leaderboard on the Display view. Notice the crown 👑 next to the top tipper. This is the social mechanism that drives competitive tipping — patrons WANT to be on this list.

ANSWERS TO COMMON QUESTIONS

What if a patron tips on Venmo but doesn't actually pay?
It's an honor system — the bump applies the moment they confirm in the app, regardless of whether they complete the payment. In practice, most people who go through the trouble of opening the payment app and entering the brewery's handle will follow through. Cash tips work the same way: trust them to settle up. If a specific person abuses it repeatedly, the staff can simply remove their request from the admin console.
What happens if Wi-Fi or internet goes down?
Patrons need the internet to submit requests, but the Display view will continue showing the last-loaded queue until connection is restored. The Admin can still mark songs played from a cached state. Once internet comes back, everything syncs automatically.
Can patrons request explicit songs?
Patrons can type any song they want — the DJ has final say on what actually plays. If a request is inappropriate, simply tap ✕ in the admin console to remove it.
What about printing QR codes for the tables?
A simple QR generator (qr-code-generator.com or similar free tool) pointed at inner-groove-dj.vercel.app creates a code in seconds. Print on cardstock, slip into table tents — a one-time setup.
What does it cost?
Nothing in monthly fees — the app runs on free-tier hosting (Vercel + Supabase). The only "cost" is occasional development if you want new features added. There are no per-transaction fees because the brewery never processes payments through the app — those go directly through Venmo / Cash App / PayPal.
What if we want a feature that doesn't exist yet?
The app was built specifically for Inner Groove and is meant to be expanded. Things like song-search autocomplete, regulars who get extra requests, themed nights with different visuals, branded merchandise tie-ins — all possible. Brian builds new features as the brewery decides what would work at the bar.

WHEN YOU'RE DONE TESTING

Two cleanup steps:

  • Go to Admin → Queue and tap CLEAR ALL to remove your test requests so they don't appear when real patrons start using the app.
  • If you turned on Charity Mode for testing, go to Admin → Charity Mode and toggle it off. Hit "RESET" to zero out the charity total.
